# PhotoMagic Studio — Master Gemini AI Image Prompt Catalog

This document specifies the exact detailed Gemini image prompts used to generate the brand's visual identity.

To replace any AI-generated scene with your actual client portfolio photos, simply drop your JPEG/PNG file into `apps/studio/public/images/<filename>` using the matching file path below. The layouts, responsive grids, and components will automatically render your portfolio photo without any code changes.

## How to Replace AI Images with Your Portfolio Photos

1. Export your photograph in **PNG** or **JPG** format (recommended width: 1600px - 2000px).
2. Save the file in:
   - `apps/studio/public/images/<filename>.png`
   - `apps/os/public/images/<filename>.png`
3. Replace the target filename (e.g., `hero_wedding_couple.png`).
4. Refresh your browser — the website will immediately display your original portfolio photograph without breaking any layout, component, or responsiveness!
